# Data Inventory and Provenance

This project rebuilds analysis from:

- `/om2/user/mabdel03/files/Isolation/Lipidomics_Work/Data/`

The original files are read-only inputs for this repository and are **not modified**.

## Repository Data Layout

- `data/raw/lipidomics_data/`
  - Contains the original SERRF-normalized lipidomics matrix exported by the prior workflow.
- `data/raw/metadata/`
  - Contains ROSMAP longitudinal/clinical metadata and the individual/sample mapping table.
- `data/raw/original_processed_csvs/`
  - Contains processed CSV outputs generated in the original analysis workspace.
- `data/processed/`
  - Contains processed outputs generated by this rebuilt pipeline.

## Key Fields Used in This Rebuild

- **Lipidomics matrix**
  - `label`, `Mode`, `lipid class`, and sample columns such as `b1.127C_R8316516`.
- **Longitudinal metadata**
  - `projid`, `social_isolation_avg`, `age_death`, `educ`, `msex`, `niareagansc`, `pmi`, medication variables.
- **Clinical metadata**
  - `projid`, `individualID`, plus demographic/clinical columns.
- **Sample map**
  - `individualID` and sample/specimen descriptors.

## Regenerating Local Data Copies

cp -p /om2/user/mabdel03/files/Isolation/Lipidomics_Work/Data/Lipidomics_Data/ROSMAP_Brain_SERRF_normalization_internal.csv data/raw/lipidomics_data/

## Git Tracking

Raw and processed CSV files are intentionally ignored by `.gitignore`. This keeps the public repository lightweight while still supporting reproducible local execution for collaborators with data access.
