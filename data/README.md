# Data Guide

This directory contains both raw inputs (local copies) and processed outputs generated by this repository.

## Folder Structure

- `data/raw/lipidomics_data/` - primary SERRF-normalized lipidomics matrix
- `data/raw/metadata/` - ROSMAP longitudinal + clinical + mapping tables
- `data/raw/original_processed_csvs/` - reference processed outputs from prior workflow
- `data/processed/` - processed outputs generated by `scripts/01_data_processing.py`

## Required Input Files

Place these files in the exact paths shown:

| Required path | Purpose |
|---|---|
| `data/raw/lipidomics_data/ROSMAP_Brain_SERRF_normalization_internal.csv` | Primary lipidomics matrix |
| `data/raw/metadata/dataset_652_basic_03-23-2022.csv` | Longitudinal phenotype metadata |
| `data/raw/metadata/ROSMAP_clinical.csv` | Clinical metadata (`projid`, demographics, pathology) |
| `data/raw/metadata/Lip_Ind_Map.csv` | Specimen-to-individual mapping |

Optional reference files (not required for pipeline execution):

| Optional path | Purpose |
|---|---|
| `data/raw/original_processed_csvs/Final_Formated_Lipidomics.csv` | Historical processed output |
| `data/raw/original_processed_csvs/Normalized_Formatted_Lipidomics.csv` | Historical normalized output |

## How to Obtain the Data

If you do not already have the raw ROSMAP lipidomics/metadata files:

1. Contact the project maintainers or data owners listed in this organization/repo.
2. Request the four required CSVs listed above.
3. Place them in the required `data/raw/` subdirectories.

If you are in an environment where a shared internal source exists, copy files from that source into `data/raw/`.

## Quick Local Copy Template

```bash
mkdir -p data/raw/lipidomics_data data/raw/metadata data/raw/original_processed_csvs
# Copy required files into the directories above.
```

## Key Fields Used by the Pipeline

- Lipidomics matrix: `label`, `Mode`, `lipid class`, sample intensity columns
- Longitudinal metadata: `projid`, `social_isolation_avg`, `niareagansc`, `msex`, `age_death`, `educ`, medication columns, `pmi`
- Clinical metadata: `projid`, `individualID`
- Mapping metadata: `specimenID`, `individualID`

## Version Control Note

Raw and processed CSV files are intentionally gitignored. This repository tracks code and documentation, while data is managed locally according to access policy.
